# 引用、镜像与许可证政策

1. 官方 handout、论文、博客、视频：只保存链接和原创摘要；版权归原作者。
2. GitHub 项目：`LICENSE` 缺失或不明确时标记 `UNKNOWN`，禁止复制代码/正文。
3. 只有明确 MIT、Apache-2.0、BSD 或 CC 等许可的小型文本才可放入 `vendor/`；
   必须同时保存来源 URL、commit、原许可证和 SHA-256。
4. `SEE_SOURCE` 表示许可证需在使用时回到原站核验；不等同于允许镜像。
5. arXiv 条目标记 `ARXIV` 只表示公开可访问，不表示允许重新分发 PDF。
6. 社区实现通常含直接答案，默认 spoiler 等级高；禁止在独立完成前复制实现。

当前 `vendor/` 不保存第三方代码或论文 PDF，只保留镜像政策说明。
